# Memory Game

Memory Game is a card matching game built with HTML, CSS, and JavaScript.

The player opens two cards at a time and tries to find all matching pairs using the minimum number of moves.

## Features

- 16 cards with 8 matching pairs
- Random card shuffle
- Moves and matched pairs counters
- New Game functionality
- Victory modal
- Cards are generated dynamically with JavaScript

## Technologies

- HTML
- CSS
- JavaScript
